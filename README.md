# CMD命令别名项目

## 项目简介
本仓库提供中英文CMD命令别名脚本，帮助用户更直观快速的使用终端命令。

## 安装使用
1. 中文环境：运行“INSTALL_CN_ALIAS.CMD”
2. 英文环境：运行“INSTALL_EN_ALIAS.CMD”

## 使用示例
中文命令：
```cmd
列出目录 /w  # 等效 dir /w
我是谁       # 等效 whoami
```

英文命令：
```cmd
ls /w      # Equivalent to dir /w
reboot     # Immediate system reboot
```

## 卸载方法
运行对应的UNINSTALL_*.CMD脚本即可恢复原始命令
